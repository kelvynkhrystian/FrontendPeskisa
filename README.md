# Peskisa - Documentação do Projeto & Stack Front-end

Este documento compila a arquitetura, as escolhas de tecnologia e o guia de configuração inicial para o desenvolvimento do front-end da aplicação **Peskisa**.

---

## 1. Visão Geral do Projeto

O **Peskisa** é uma aplicação web voltada para a gestão e execução de pesquisas de campo.

## 2. Stack Tecnológica

- **Core:** React 19 + TypeScript + Vite
- **UI:** Tailwind CSS + Shadcn UI (Radix UI)
- **Ícones:** Lucide React
- **Estado & API:** TanStack Query + Axios
- **Formulários:** React Hook Form + Zod
